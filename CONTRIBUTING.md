# Participar do SapoConnect

O desenvolvimento e as publicações do SapoConnect são mantidos por Luca Versiani. A melhor forma de participar é registrar uma sugestão ou um problema no GitHub para que a conversa permaneça pública e organizada.

- [Sugerir uma melhoria](https://github.com/lucaversa/sapoconnect/issues/new?template=feature_request.yml)
- [Relatar um problema](https://github.com/lucaversa/sapoconnect/issues/new?template=bug_report.yml)

## Privacidade

Nunca publique RA, senha, notas, nomes de professores, capturas sem tratamento ou outros dados acadêmicos pessoais. Remova essas informações antes de anexar uma imagem.

## Relatos úteis

Informe a área afetada, os passos para reproduzir, o resultado esperado, o aparelho e o navegador. Quando a falha envolver carregamento, confira também se o portal oficial da TOTVS está disponível.
